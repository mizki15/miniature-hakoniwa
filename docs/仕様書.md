## 1. 概要

ブラウザで動くボクセルの箱庭（ジオラマ）。自然の中を眺めることが中心で、畑・植林・地形の編集などで少しだけ手を加えられる。現実の時刻・全世界共通の季節と天気に合わせて箱庭が変化し、閉じている間も時間が進む。

| 項目 | 内容 |
|---|---|
| 動作環境 | PC のブラウザ（Chrome / Edge / Safari / Firefox の最近の版）。WebGPU、非対応なら WebGL2 で動く |
| スマホ | 閲覧のみ（パネル・モード切り替え・道具は出さない） |
| サーバー | 静的ファイルの配信だけ。処理と保存はすべてブラウザ内 |
| 技術 | TypeScript / Vite / three.js r187（WebGPURenderer・TSL） |
| 起動 | `npm run dev` → http://localhost:5173（本番ビルド：`npm run build`） |

## 2. 画面構成

```
┌──────────┬───────────────────────────┬──────────┐
│ 生き物図鑑 │ デバッグウィンドウ（左上）       │ ステータス │
│（見る）    │                             │（見る）    │
│ または     │         箱庭（画面いっぱい）     │          │
│ エディタ   │                             │          │
│（エディタ） │   [見る V][エディタ E][☰ メニュー Esc] │          │
└──────────┴───────────────────────────┴──────────┘
```

- 箱庭は画面全体に描き、パネルはその上に浮かぶ **すりガラス** の板
- パネルの色は時間帯で自動で切り替わる
  - 昼：明るいすりガラス＋濃い文字
  - 夜：暗いすりガラス＋明るい文字（空の暗さが 0.65 を超えたら夜、0.45 を下回ったら昼。間はそのまま）
- 左右のパネルは ‹ › でたためる
- 画面下中央：モード切り替え（見る・エディタ）と「☰ メニュー」ボタン
- 一時的なお知らせ（トースト）は画面下に数秒表示
- 狭い画面（幅 760px 以下）：左右パネル・モード切り替え・道具・ホバー情報を出さず、デバッグウィンドウは最初たたんだ状態

## 3. モードと操作

### 3.1 モード

| モード | キー | 表示 | マウス |
|---|---|---|---|
| 見る | V | 左：生き物図鑑、右：ステータス | 左ドラッグ：回転／右ドラッグ：移動／ホイール：ズーム（カーソルの位置へ） |
| エディタ | E | 左：エディタ（道具・種・説明） | 左ドラッグ：道具を使う／右ドラッグ：回転／中ドラッグ：移動／ホイール：ズーム |

- 起動時は「見る」
- Esc はメニューの開閉（モードは変えない）

### 3.2 キー一覧

| キー | 動作 |
|---|---|
| V / E | 見るモード／エディタモード |
| 2〜8 | エディタの道具を選ぶ（見るモード中に押すとエディタへ切り替わる） |
| Esc | メニューを開く・閉じる |

- 入力欄・選択欄にフォーカスがある時は、キー操作を受け付けない
- メニューを開いている間は Esc 以外のキーを受け付けない

### 3.3 カメラ

| 項目 | 値 |
|---|---|
| 投影 | 透視投影、縦の画角 28°（ミニチュアらしさと奥行きのバランス） |
| 仰角 | 真上近く（5°）〜水平より下（105°、見上げる角度） |
| 距離 | 最短 3、最長 フィールドの一辺 × 3.2 |
| 初期位置 | 斜め上から全体が入る距離。縦長の画面では遠めから |
| 地面との関係 | カメラが地面（または水面）の 0.5 上より下に潜らない |
| 90° 回転 | デバッグウィンドウの「⟲ 90°」「90° ⟳」で、なめらかに 90° ずつ回る |
| 自動周回 | デバッグウィンドウの「自動周回」でゆっくり回り続ける |
| 近くの物 | カメラのすぐ近く（2.5〜9）の木・花・作物は、点描のように透けて視界をふさがない |

### 3.4 見るモードのホバー情報

- 対象は **作物と動物だけ**（ふつうのブロックや苗木には出さない）
- マウスの横に小さな情報カードを出す。作物のマスは水色の枠で示す
- **短い右クリック** で情報を固定（カードに「📌 固定中」）
  - 固定中は対象の横に表示し、動物が動けばついていく
  - 解除：短い右クリック（何もない所、または同じ物）。別の作物・動物なら固定先が変わる
  - 左クリックでは解除しない。右ドラッグ（視点の移動）では変わらない
  - 収穫などで対象がなくなったら自動で解除
- 水面を左クリックすると波紋が立つ

| 対象 | 内容 |
|---|---|
| 作物 | 名前、生育段階（芽が出た／若い／育ってきた／収穫できる）、湿り具合（水やり済み／水路のそば／雨でしっとり／乾いている）、収穫までの残り時間の目安、季節外れの注意、育ち具合のバー |
| 動物 | 名前、種類、いましていること（散歩中／ひと休み／眠っている）、好きなもの、得意なこと |

### 3.5 エディタモード

左のサイドバーに道具の一覧（アイコン・名前・キー・説明）、種の選択、いま指している所の判定、操作方法を出す。

- 指しているマスに枠を表示：使える所は白、使えない所は赤（理由をサイドバーに表示）
- **左ドラッグでなぞった所にまとめて使う**
  - 数ピクセルおきに判定するので、速く動かしても抜けない
  - 1 回のなぞりで同じ列には 1 回だけ（掘りすぎ・積みすぎ防止）
  - なぞっている間も枠はマウスについていく（使った直後のマスが赤く見えないよう白のまま）
  - 終わると「◯ マスに「耕す」を使いました」のようにまとめて知らせる

| キー | 道具 | 使える所 | 結果 |
|---|---|---|---|
| 2 | ⛏ 耕す | 草地か土の上面（その列の一番上）。木の根元・耕し済みは不可 | 畑（耕した土）にする。その列の花は消える |
| 3 | 🌱 種まき | 畑で、まだ何も植えていない所 | 選んでいる種をまく |
| 4 | 💧 水やり | 畑 | 6 時間（箱庭内の時間）湿らせる。湿っている所にもう一度やると延長 |
| 5 | 🧺 収穫 | 育ちきった作物 | 持ち物に 1 つ加える。育ちきっていなければ育ち具合を表示 |
| 6 | 🌳 植林 | 草地か土の上面。まわり 1 マス以内に木があると不可 | 苗木を植える（高い所＝高さ 20 以上は針葉樹） |
| 7 | 🕳 掘る | 一番下（高さ 0）以外のブロック。木の根元は不可 | ブロックを消す。水のそばを掘ると水が流れ込む |
| 8 | ⬆ 土を盛る | 指した面の隣が空気か水。上から 2 段・外周の外・木の列は不可 | 土のブロックを置く |

- 種：🥬 カブ（1.5 時間）、🌾 小麦（6 時間）、🎃 かぼちゃ（8 時間）。種のボタンを押すと種まきの道具になる
- 畑を掘ったり上に土を盛ったりすると、その列の作物と畑は消える（上に盛った時、下の畑は土に戻る）

## 4. 箱庭（地形）

### 4.1 大きさ

| 項目 | 値 |
|---|---|
| フィールドの一辺 | 64 / 128（標準）/ 192 / 256 / 384 |
| 高さ | 64 ブロック（地表は最大 58） |
| 水面の高さ | 10（この高さより下の空いている所が水） |
| 台座 | 地形の下に木の板（一辺＋3、厚さ 2.4） |

### 4.2 ブロックの種類

| 番号 | 種類 | 備考 |
|---|---|---|
| 0 | 空気 | |
| 1 | 草 | 上面の色は季節で変わる。側面は濃い緑、下面は土色 |
| 2 | 土 | |
| 3 | 岩 | |
| 4 | 砂 | |
| 5 | 水 | |
| 6〜12 | 幹・葉・針葉・茎・花びら（赤・黄・白） | 小物（木・花）のモデル用 |
| 13 | 畑（乾いている） | 上面に畝の筋 |
| 14 | 畑（湿っている） | 色が濃い |

### 4.3 地形の作り方

シード値（整数）から決定論的に作る（同じシード・同じ設定なら同じ地形）。

1. **高さ**：ノイズの重ね合わせ
   - 細かな丘：12.5 ＋（fbm × 7 ＋ 丘 × 9）× 起伏の激しさ
   - 大きな起伏：最大 22 × 山の高さ
   - 湖：低い周波数のノイズで窪地を作る（水の多さで広さが変わる）
   - 川：X 方向に蛇行する 1 本（水の多さ 0.15 以下なら作らない。幅は水の多さとフィールドの大きさで変わる）
   - 高さは 3〜58 に収める
2. **地表の種類**（同じ高さでも混ざる）
   - 水面以下・水辺（水面＋2 まで）の一部 → 砂（砂浜が内陸に入り込む）
   - 高さ 35 以上、または岩場のノイズ → 岩
   - 土がむき出しのノイズ → 土
   - それ以外 → 草
   - 地表の下 3 段は土（岩場の下は岩）、さらに下は岩
3. **水**：水面より下で空いている所を水で満たす
4. **木**：草地（水面＋2 より上）に置く。森のノイズが濃い所は多く、まばらな所は少なく（森の密度で増減）。木同士は 2 マス以上離す。高さ 20 以上は 75%、それ以外は 15% が針葉樹
5. **花**：草地（木の根元以外）に置く。花畑のノイズが濃い所に多く（花の密度で増減）。1 マスの中で位置・向き・大きさをばらつかせる

### 4.4 地形のパラメータ（デバッグウィンドウ「地形のパラメータ」）

| パラメータ | 範囲 | 効果 |
|---|---|---|
| 起伏の激しさ | 0〜2.5 | 細かな丘の高さ |
| 山の高さ | 0〜2.5 | 大きな起伏の高さ |
| 水の多さ | 0〜2 | 湖の広さ・川の幅（0.15 以下で川なし） |
| 岩場の多さ | 0〜2 | 岩の地表の割合 |
| 森の密度 | 0〜3 | 木の数 |
| 花の密度 | 0〜3 | 花の数 |

- 標準はすべて 1。「標準に戻す」ボタンあり。変更は「生成」で反映

### 4.5 小物（木・花）

- 地面とは別の細かいボクセルで作り、インスタンス描画（同じ形を大量に描く）
- 細かさ（デバッグ「小物」）：地面のボクセルに対して **1/1・1/3（標準）・1/4**
- 形は地面の単位の連続的な形として定義し、細かさで標本化する（細かさを変えても同じ形・大きさ）
- **木**：6 種類
  - 広葉樹 4 種：幹（上に行くほど細い）＋ノイズで揺らした球を重ねた樹冠。細かいボクセルの時は枝も
  - 針葉樹 2 種：段々になった円すい。冬は上面に雪
  - 向き（90° 単位）と大きさ（0.85〜1.2 倍）をばらつかせる
- **花**：赤・黄・白の 3 種
  - ローポリ（標準）：茎・葉・花びら 5 枚・花芯
  - ボクセル：細かさ 1/3 以上の時だけ作れる（1/1 の時はローポリになる）
  - 冬は表示しない
- **風**：根元からの高さに応じて揺れる（2 つの周期を重ねたゆったりした動き、先端で最大 0.25）。花は背が低いので高さに比例した揺れも足す。天気で風の強さが変わる

## 5. 見た目（描画）

### 5.1 地形のシェーダー

| 機能 | 内容 |
|---|---|
| 頂点 AO | ブロックの隅を暗くする（メッシュを作る時に計算） |
| 境界のなじませ | 同じ平面上の隣の面の色を、ノイズで揺らした双線形補間で混ぜる（違う種類のブロックの境目をぼかす。違う平面とは混ぜない）。強さはデバッグ「境界のなじみ」（0 = くっきり〜1 = なめらか） |
| 角丸（ベベル） | 法線を縁で曲げて丸く見せる（形は立方体のまま）。段差の外側の角は外へ、入り隅は壁から離れる向きへ。同じ平面の継ぎ目は曲げない（溝ができない）。デバッグ「角丸」で ON/OFF |
| 色のゆらぎ | ボクセルごとの弱いゆらぎ＋なめらかなノイズ |
| 季節の色 | 草の上面の色を季節で変える（冬は雪） |
| 雪 | 冬は上向きの面すべてに積もる。高さ 41〜47 から上は一年中（上向きの面は濃く、側面は薄く） |
| 畑 | 上面に畝の筋 |
| コースティクス | 水面より下の上向きの面に、揺らめく光の模様（外周の断面には出さない） |
| 雲の影 | 上空の雲の模様に合わせて地面を暗くする（流れる） |
| ホタルの光 | 近くのホタルが地面や草木をほんのり照らす |
| 影 | 太陽（夜は月）の影。角丸の縁で影がギザギザにならないよう、影の参照位置は曲げる前の法線方向にずらす |

- 地形は 32×32 マスの **チャンク** に分けてメッシュを作る（Greedy Meshing：同じ種類・同じ AO の面をまとめる）
- メッシュ作りは Web Worker（別スレッド）で行う

## 6. 時間・季節・天気

### 6.1 時刻（昼夜）

- 端末の現在時刻と連動（デバッグ「時刻」スライダーで上書き、「現在」で戻す）
- 6 時に日の出、18 時に日の入り。夕方・明け方は空と光が赤みを帯びる
- 昼は太陽、夜は月（反対側の空）から照らす。夜はホタルが映えるよう暗め
- 曇り・雨の日は日差しが弱まり、空が灰色がかり、空からの光を少し増やす

### 6.2 季節（全世界共通の暦）

- 基準日 2027-01-01（UTC）を春の始まりとし、**現実の 1 か月で 1 季節**（春→夏→秋→冬で 4 か月）
- 季節の切り替わりは UTC の月初（日本時間 1 日の 9:00）。月の最後の 3 日間で次の季節の色へ少しずつ移る
- 端末の時刻だけで計算する（サーバー不要、全プレイヤーが同じ季節）
- デバッグ「季節」で上書き可（「暦どおり」で戻す）

| 季節 | 草の上面 | 広葉樹の葉 | その他 |
|---|---|---|---|
| 春 | 明るい若草色 | 若葉色 | |
| 夏 | 濃い緑 | 深い緑 | ホタルが一番多い |
| 秋 | 黄土色 | 橙色 | |
| 冬 | 雪（白） | 雪をかぶった色 | 上向きの面に雪、花は隠れる、針葉樹の上面に雪 |

### 6.3 天気（全世界共通）

- 90 分ごとの時間帯ごとに、時刻から決定論的に決める（同じ時刻ならどのプレイヤーも同じ天気）
- 冬の降水は雪、それ以外は雨
- 切り替わりは数分かけてゆっくり（手動で変えた時は速め）
- デバッグ「天気」で上書き可（「自動」で戻す）

| 季節 | 晴れ | くもり | 雨・雪 |
|---|---|---|---|
| 春 | 50% | 30% | 20% |
| 夏 | 60% | 20% | 20% |
| 秋 | 55% | 30% | 15% |
| 冬 | 40% | 30% | 30%（雪） |

| 天気 | 雲の量 | 日差し | 風 | その他 |
|---|---|---|---|---|
| 晴れ | 少ない | 100% | 0.8 | 夜は流れ星 |
| くもり | 多い | 55% | 1.1 | |
| 雨 | ほぼ全面・暗い | 32% | 1.6 | 雨粒、水面に雨の波紋、畑が湿る |
| 雪 | 多い | 45% | 0.6 | 雪の粒 |

- 雨・雪の粒は GPU 上で時刻から位置を計算する（CPU の負担なし）。粒の数はフィールドの広さに比例（128 で雨 5000・雪 3500、最大 4 倍）

## 7. 生き物

### 7.1 住人（動物）

## 8. 畑と植林（育つ要素）

### 8.1 作物

| 作物 | 育つ時間（現実の時間） | 旬の季節 |
|---|---|---|
| 🥬 カブ | 1.5 時間 | 春・秋 |
| 🌾 小麦 | 6 時間 | 春・夏・秋 |
| 🎃 かぼちゃ | 8 時間 | 夏・秋 |

- 育つ速さ
  - 湿っている（水やりから 6 時間・雨の間・水路のそば＝水平に 3 マス以内に水）：1 倍
  - 乾いている：0.5 倍
  - 季節外れ：0.35 倍、冬：育たない
- 生育段階：芽（0〜25%）→ 若い（25〜60%）→ 育った（60〜100%）→ 収穫できる（100%）。段階ごとに見た目（ローポリ）が変わる
  - カブ：葉が増え、白い根が見えてくる
  - 小麦：茎が伸びて穂が付き、金色になる（1 マスに 4 株）
  - かぼちゃ：つるの葉が広がり、緑の実が橙色に（1 マスに 1 株）
- 雨の間はすべての畑が湿る。湿った畑はブロックの色が濃くなる（1 秒ごとに反映）
- 収穫すると持ち物に 1 つ加わる（今は数えるだけで、使い道はまだない）

### 8.2 植林

- 苗木 → 若木 → 木 と **24 時間** で育つ（冬は 0.2 倍の速さ）
- 植えた場所の高さで種類が決まる（高さ 20 以上は針葉樹、それ以外は広葉樹）
- 育ちきった木は生成された木と同じ見た目

### 8.3 時間の扱い

- 成長は「箱庭内の時計」で計算する。ふだんは現実の時間と同じ速さ
- 閉じていた間の分は、次に開いた時にまとめて進める（→ 9.3）
- デバッグ：時間の流れ ×1／×60／×600、「+1時間」「+6時間」で早送り

## 9. 保存

### 9.1 セーブデータ

- 地形はシードから作り直せるので、**生成の設定＋変えた所（差分）＋畑の状態** だけを保存する
- JSON を gzip で圧縮。例：畑 8 マス・作物 8・苗木 1 で約 0.3 KB
- 形式のバージョン（現在 1）を持ち、古い形式を読む仕組み（migrate）がある。新しいバージョンのデータは読まずに知らせる

| 中身 | 内容 |
|---|---|
| version / savedAt | 形式のバージョン、保存した現実の時刻 |
| world | シード、サイズ、高さ、小物の細かさ、花の種類、地形のパラメータ |
| edits | 変えたボクセル（番号と種類の組） |
| farm | 箱庭内の時計、持ち物、作物（列・種類・育ち具合）、苗木（列・種類・向き・育ち具合）、湿っている期限 |

- 保存しないもの：画質・時刻や季節や天気の上書き・カメラ位置などのデバッグ設定

### 9.2 保存先とタイミング

| 保存先 | タイミング・操作 |
|---|---|
| この端末（IndexedDB） | 自動：変更があれば 1 分ごと（早送り中も 1 分ごと）、なくても 5 分ごと、ページが隠れる・離れる時。メニュー「今すぐ保存」 |
| ファイル（.hakoniwa） | メニュー「ファイルに書き出す」「ファイルから読み込む」 |
| Google Drive | メニュー「Google Drive と同期」（アプリ専用フォルダ、要設定） |

- 初めて保存する時に、ブラウザへ「消さないで」（永続化）を頼む。断られたらメニューに「書き出しで控えを」と表示
- 保存は 1 つ（main）だけ

### 9.3 読み込み

- 起動時、この端末に保存があれば読み込む。なければ新しい箱庭を作って保存する。読めなかった時は新しい箱庭を作って知らせる
- 差分はワーカーで地形に当ててからメッシュを作る（変えた列の花は取り除く）
- **閉じていた間の成長（オフライン進行）**：閉じていた時間（最大 7 日）を 15 分ずつ、その時々の季節・天気（雨なら畑が湿る）で進める。3 分以上たっていれば「おかえりなさい。◯時間たちました：◯ マスの作物が実りました・◯ 本の木が育ちました」と知らせる
- ファイル・Drive から読み込む時も同じ（今の箱庭に変更があれば上書きの確認をする）

### 9.4 作り直しと上書きの確認

| 操作 | 今の箱庭 |
|---|---|
| 「生成」ボタン・サイズの変更（新しい箱庭） | 変更（地形・畑・苗木）があれば上書きの確認。キャンセルで元に戻す。作ったらすぐ保存 |
| 小物の細かさ・花の種類・画質（地形の簡略化）の変更 | 保ったまま作り直す |

### 9.5 Google Drive 同期

- ブラウザから直接 Drive API を呼ぶ（サーバーなし）。スコープは drive.appdata（アプリ専用の隠しフォルダ、他のファイルは見えない）
- 認証は Google Identity Services のトークンモデル（アクセストークンは約 1 時間。切れていたら押した時に取り直す）
- Drive の方が新しい（5 秒以上）時は「Drive を読み込む／この端末で上書き」を確認する
- Client ID は環境変数 `VITE_GOOGLE_CLIENT_ID`（`.env.local`、Git の対象外）。未設定ならボタンを押すと設定が必要な旨を表示
- **未検証**（Client ID がないため、実際の同期は動かしていない）

## 10. Esc メニュー

- Esc（または画面下の「☰ メニュー」）で開閉。✕ ボタン、パネルの外のすりガラス部分を押しても閉じる

- 開いている間は描画は続くが、箱庭への操作とキー（Esc 以外）は受け付けない

| 欄 | 内容 |
|---|---|
| 💾 保存 | 最後に保存した時刻・大きさ・永続化の状態、今すぐ保存、ファイルに書き出す、ファイルから読み込む、Google Drive と同期 |

| 🎮 操作 | キーとマウスの操作の一覧 |

- **全画面表示**：Fullscreen API。ブラウザの Esc などで抜けた時もスイッチを合わせる。使えないブラウザ（iPhone の Safari など）ではスイッチを無効にして理由を表示。1.5 秒たっても切り替わらなければ（埋め込み表示など）知らせる

## 14. 性能と通信量（2026-11-12 の実測）

### 14.1 描画の速さ（1280×720、1 フレームの描画時間）

| 環境 | 高 | 中 | 低 |
|---|---|---|---|
| RTX 3060 Ti（WebGPU） | 0.96ms | 0.95ms | 0.37ms |
| RTX 3060 Ti（WebGL2） | 2.1ms | 1.4ms | 0.32ms |
| GPU なし（Windows のソフトウェア描画、Ryzen 5 5600X） | 約 12fps | 約 13fps | 約 40fps 以上 |

- フィールドの広さ：384 で約 342 万三角形（高さ 64）。高さ 40 だった時の計測では、384 でも GPU ありで 160fps 前後
