# エフェクト一覧（v0.21.0 の案・確認用）

ほぼすべての動作に、ビジュアルエフェクト（VFX）とサウンドエフェクト（SFX）を付けるための一覧です。
確認していただいた後、VFX はこのセッションで作り（絵の素材は ChatGPT に頼む）、SFX はコマンドラインの Claude Code で lumina-sfx スキルを使って作ります。

- 1 章：共通の方針（見た目と音のトーン、鳴らし方の決まり）
- 2〜7 章：エフェクトの一覧（いつ・VFX・SFX）。ID は SFX のプロンプト（8 章）と、絵の素材（9 章）に対応
- 8 章：lumina-sfx に渡すプロンプト（検索フレーズと、詳しい音の説明）
- 9 章：ChatGPT に頼む絵の素材
- 10 章：決まったこと（2026-11-28 の確認）

## 1. 共通の方針

### 1.1 トーン

- **見た目**：ローポリの箱庭に合う、やわらかく丸いパーティクル。色は淡めで、彩度は少しだけ高く。光るものは控えめ（ブルームが強く効きすぎないように）。1 回のエフェクトは 0.4〜1.2 秒で消える。画面を覆わない
- **音**：「手のひらの上の小さな世界」。やさしい、木と土と布の質感の、実際の物音（フォーリー）が中心。電子音っぽいピコピコは使わない（UI だけは、柔らかい木琴・オルゴールのような音色に統一）。高い音は耳に刺さらないよう 8 kHz より上を控えめに。余韻は短く、屋外（`outdoor_open`・反響 0.1〜0.2）

### 1.2 鳴らし方の決まり（実装する側の約束）

| 決まり | 内容 |
|---|---|
| 聞き手 | カメラの注視点（画面の真ん中の地面）。箱庭の中の物の音は、その物の位置から鳴らす（左右に振り、遠いほど小さく・こもらせる。注視点から 60 マスより遠い音は鳴らさない） |
| 画面の操作の音 | UI（ボタン・窓・選択バー）は聞き手の位置で、左右に振らない |
| ばらつき | 1 つの音に 3 通りの録り（バリエーション）。鳴らすたびに少しだけ高さ（±1 半音）と明るさを変える（lumina の `SfxPlayer.play()` が自動でする） |
| 同時に鳴る数 | 同じ音は同時に 3 つまで。なぞって何マスも掘る時などは、2 つ目から少し小さく・間引く（0.06 秒より詰めて鳴らさない） |
| 優先度 | 高：目標の達成・区画を開く・建物の完成・初めての発見／中：プレイヤーの操作の結果／低：時間で起きる変化・生き物の気配・環境音。高い時は、低い音を 0.5 秒ほど下げる |
| 音量の段 | 環境音のベッド −24 dB 前後、時間で起きる変化 −20 dB、操作の結果 −14 dB、知らせ・達成 −10 dB（最大）。設定に「効果音の大きさ」「環境音の大きさ」を分けて置く |
| 時間で起きる変化 | 作物が育つ・草が生える・木が大きくなるなどは、画面に映っている所で、注視点の近く（30 マス以内）だけ鳴らす。遠い所は見た目だけ |
| 早送り | 時間の流れ ×60・×600 の時は、時間で起きる変化の音を鳴らさない（見た目は残す） |
| 閉じていた間 | 「おかえりなさい」でまとめて進めた分は、まとめて 1 つの知らせの音だけ |

### 1.3 VFX の作り方（実装の方針）

- パーティクルは 1 つの仕組み（GPU のインスタンス描画の板ポリゴン。カメラの方を向く）で全部を描く。絵は 1 枚のテクスチャ（9 章のアトラス）から切り出す
- 色は粒ごとに付けられる（同じ「かけら」の絵で、土・石・木などの色を変える）
- 形の変化（ぽよんと縮む・伸びる・揺れる）は、モデルの大きさを動かす（パーティクルではない）
- 「＋3」などの数字は、HTML の文字（画面の上に重ねる）で出す

Project: a cozy miniature voxel diorama game in the browser (three.js / Web Audio, TypeScript).

## 9. ChatGPT に頼む絵の素材（VFX）

パーティクルの絵を 1 枚のアトラス（2048 × 2048、透明の背景の PNG、1 コマ 256 × 256 の 8 × 8 マス）にまとめます。ChatGPT の画像生成に、次の共通の指定と、コマの一覧を渡します（何枚かに分けて作ってもらい、こちらで並べてもかまいません）。

### 9.1 共通の指定

```text
Create sprite art for particle effects in a cozy low-poly miniature diorama game.
Style: soft, rounded, flat-shaded shapes with one gentle highlight, no outlines or a very thin darker outline,
pastel-but-saturated colours, readable at 24–48 px on screen. Transparent background (PNG with alpha).
Each sprite is centred in its own 256×256 cell with ~20 px padding, no drop shadow, no text.
Particles that are tinted in-game (marked "white") must be drawn in white/light grey with soft shading only,
so the game can multiply a colour onto them.
```

### 9.2 コマの一覧

| 番号 | 名前 | 内容（ChatGPT への説明） | 使う所 |
|---|---|---|---|

## 10. 決まったこと（2026-11-28 の確認）

1. たくさん同時に起きる物（草が生える・森が広がる・花が枯れる など）は、音なし
2. 生き物の声（住人 16 種類・訪問者 24 種類、寝息・あくび・鼻歌）は、一旦なし。撫でる・餌は、毛の音・食べる音と、カリンバの 1 音で
3. BGM は付けない。季節が変わった時と、目標の達成などの短いメロディだけ
4. 環境音（風・水・雨・鳥・虫・雪・波・森）は、今の合成した音を lumina のループに置き換える
5. UI と達成の音は、木琴・カリンバ・オルゴールにそろえる
6. 9 章の絵は ChatGPT（画像生成）に頼む。素材 5 つ・作物 10 種類のアイコンも一緒に作り直す（9.3）

### 進め方

- VFX：このセッションで作る（パーティクルの仕組みと、各場面へのつなぎこみ。絵は ChatGPT）
- SFX：コマンドラインの Claude Code で、8 章のプロンプトと lumina-sfx スキルを使って作り、`src/audio` に入れる。ゲームの側には、ID ごとに鳴らす呼び出し口（`sfx.play('A01', 位置)`）を先に用意しておき、音が届いたら ID でつなぐ
